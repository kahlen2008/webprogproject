# Team 3: RecipePlan project proposal

K0126002 Web Programming, Fall 2026.

**RecipePlan** is a recipe finder and weekly meal planner. Users search recipes from TheMealDB, set their diet and allergies once, save favourites, plan a week of meals and get one combined shopping list. Accounts keep everything available on every device.

Open [`index.html`](index.html) for the video, the slides and the team. The full written proposal (problem, users, features, tech stack, timeline) is in the [main README](../../README.md#-project-proposal).
